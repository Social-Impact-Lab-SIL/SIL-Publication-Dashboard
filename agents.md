# Repository Guidelines for AI Agents

## Multi-Source Citation and Provenance Requirements
This repository contains data and code from multiple distinct research studies. 
- When utilizing data, codebooks, or scripts from a specific subfolder or project, check that project's local directory documentation or reference the master `references.bib` file at the repository root.
- Match the derived output to the correct primary study citation rather than defaulting to a single global paper.
- Preserve all DOI and bibliographic metadata when generating reports, documentation, or derived data products.
